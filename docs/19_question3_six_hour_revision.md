旧版也在0/6/12/18点重算，问题在于预测/优化时域为432、396、360、324段，始终延伸到第三天；不是每三天才决策一次。现将更新间隔固定为6小时、预测时域固定为未来24小时、每次只执行头6小时。这样既使用最新预报，又保留低价充电服务后续高价段的能力。若只优化未来6小时，则仍可能在六小时末透支储能，无法完整比较用户提出的24小时内保留电量方案。

## 2. 六小时滚动时序

令r为0:00、6:00、12:00、18:00之一，时段长度Δ=1/6小时。

1. 0:00锁定当天144段原计划q。未来尚未发布的本日6/12/18点预报不得进入q。
2. 每个r更新预测，在[r,r+24h]内优化；执行/结算头36段，未来草案可在下一次发布重算。
3. 对当日剩余段，g相对于当日0点的q结算；跨入次日的部分尚无次日合同，暂按基础价格作展望变量，次日0点重算并成交。不得把本日18点草案当成已成交的次日q。
4. 已结束时段、电量与费用不可回写；SOC在六小时块之间和日期之间连续。12月31日窗口可以含2026年预测，只回放至2025年12月31日24:00。

日初q仍采用开环24小时随机计划，未在根节点精确联合优化所有未来预报版本的价值；这是继承队友框架的滚动近似，不称为全年全局最优策略。

## 3. 按相同有效时间融合预报

2026-09-12后续更新：1月1日0/6/12点明确只用最新预报，18点后再融合。月度权重稳定性与因果回测见[20号文档](20_question3_monthly_weights.md)；可选动态模式与Claude全年执行步骤见[21号文档](21_question3_claude_weight_run.md)。下文固定1月系数仍是默认基线，不代表所有月份各自的最佳拟合值。

对目标结束时刻τ，只融合满足v≤r且0<τ−v≤24小时的已发布版本v。每个版本用其发布时点已知的光伏边界观测与24个整点预报分别线性插值，得到P̂(τ|v)，再按从新到旧加权。不能把不同目标时刻的“预报1小时”直接平均，也不能对旧版本24小时之外进行外推。

```math
\widehat P_{\tau|r}=\sum_{v\in\mathcal V(r,\tau)}w_{r,\tau,v}\widehat P(\tau|v),\qquad
\sum_vw_{r,\tau,v}=1,\quad w_{new}\ge w_{old}\ge0.
```

当已形成连续四次发布周期后，未来(0,6]小时有4个版本，(6,12]有3个，(12,18]有2个，(18,24]只有1个。例如当天18点到次日0点，按18、12、6、0点顺序融合；过了次日0点，当天0点版本已过期，不能继续赋权。

权重由1月光伏实际值和历史预报的约束最小二乘拟合，目标为均方误差最小，约束非负、和为1、新版本权重不小于旧版本。按四个提前期组分别拟合，避免人为认定0.4/0.3/0.2/0.1最佳。第二问的0.92是历史日样本年龄衰减，不能直接搬成预报版本每6小时衰减。

先以1月4–20日发布训练，1月22–30日发布验证，所有目标在2月前结束；再用1月4–30日发布及其已实现目标重拟合，固定用于2–12月。1月预热用预先给定0.92衰减作启动规则，不能用月末权重倒灌1月决策。

## 4. 退款与保留必须由同一优化问题决定

按本次用户明确的口径：取消的计划电量净退回原单价的50%。记u=(g−q)+、h=(q−g)+，则已签当天合约的完整结算为：

```math
K_t=p_tq_t+1.5p_tu_t-0.5p_th_t+5p_te_t.
```

等价于原单价退还全部取消部分、再收50%违约费；不能再额外扣一次退费或再加一次违约费。100kWh计划、1元/kWh、减至80kWh时结算90元；增至120kWh时130元。

直接使用凸分段费用上图形式，避免负退款项被任意增大：

```math
z_t\ge0.5p_t(q_t+g_t),\quad
z_t\ge1.5p_tg_t-0.5p_tq_t,\quad g_t\ge0.
```

目标中最小化z，自然得到正确分段结算；不再设置g≥q，不把退款量h只用下界线性化。不允许事后拿真实负载确定当天已成交段的退款。

保留某时段已买的1kWh，放弃的退款收益为0.5p_t。若通过储能未来释放，可用母线电量最多0.9×0.9=0.81kWh；未来边际购电成本为m_τ时，忽略其他机会成本的必要比较为0.81m_τ与0.5p_t。m_τ可能是基础、增购或应急价格，不能固定当成p_τ。容量、充放电功率、其他光伏占用和预测不确定性由联合约束处理。

保留与退款是同一个g、充放电和SOC联合优化中的两种选择，不是先强制退款再独立补购，也不能把不同时段电量直接账面抵消。价格低、未来需要且有储能空间时可保留；未来无用途或储能已满时可退款。仍可能有无法利用/无法提前预知的余量，不能预先要求弃电为0。

## 5. 24小时随机调度与物理约束

购电g跨情景共享；c、b、e、w、S按情景独立，所有电量为kWh。每天144段，每次只承诺头36段，未成交部分仅参与展望。目标为当天剩余合约分段费用、跨日未签计划费、期望5倍应急费之和，另保留队友的小吞吐惩罚及软末端价值：

```math
\min\sum_{t\in J_r}z_t+\sum_{t\notin J_r}p_tg_t+
\sum_s\rho_s\left[\sum_t5p_te_{s,t}+10^{-5}\sum_t(c_{s,t}+b_{s,t})-\lambda S_{s,H}\right].
```

在0点尚未形成q时，所有g按p计费并锁定为q。J_r表示后续发布时已经有当日q的时段。实付费用不包含末端奖励和吞吐惩罚。λ沿用队友高价均值乘放电效率的估值，并明确标为近似参数；取消三日4000–8000kWh硬末端门槛，避免把第三天状态要求强行压到24小时末。

```math
g_t+b_{s,t}+e_{s,t}=N_{s,t}+c_{s,t}+w_{s,t},\qquad
S_{s,t}=S_{s,t-1}+0.9c_{s,t}-b_{s,t}/0.9,
```

```math
1200\le S_{s,t}\le10800,\quad
0\le c_{s,t}\le(5000/6)y_{s,t},\quad
0\le b_{s,t}\le(5000/6)(1-y_{s,t}),
```

```math
0\le e_{s,t}\le[N_{s,t}]_+(1-y_{s,t}),\quad w_{s,t}\ge0,\quad y_{s,t}\in\{0,1\}.
```

新版采用MILP严格实施优化内部互斥及禁止应急充电，不再以微小惩罚代替约束。有限情景独立补救仍带有乐观近似，不能称为完整非预知场景树。实际执行先沿用队友逐段盈余充电、缺口放电后应急补足的因果控制，以隔离本次预报/合约修改效果；不是把情景中提前知道整条路径的储能动作直接回放。此贪心执行与优化期望可能偏离，必须看实际费用而非只看MILP目标。

## 6. 目标、验证与下一步数值边界

主目标仍是期望总电费最小，5倍应急价格已经体现高代价。紧急电量最小若脱离成本，会通过过量预购走向平凡的低应急方案，不符合用户已确认目标。不得把“更多预报”作为必须降低每一天应急量的约束，也不得承诺无法证明的全年最小应急量。

比较需报告总费、计划费、增购费、退款额、应急费用/电量/时段数、余量、首末SOC和实际储能行为。要分别区分加权预报、24小时滚动、退款三个变化；与旧版直接比较的差额不能全称为预测信息价值。新版自身应比较相同退款机制下“最新单版本”和“加权版本”，以及禁止日内调整的对照。统一1月预热初值或同时报告各自初值，不能硬抄旧版8809.74kWh。
