# 第 3 步：数学模型

状态：模型结构已建立；真实附件已核对；未开展最优调度求解。题设与补充解释见 [数据约定](03_data_contract.md)。数学公式使用 GitHub 支持的 LaTeX。

## 1. 周期、符号和信息集

日期为 $`d`$，每个周期包含 $`t=1,\ldots,144`$ 个记录，记录标签从当天 0:10 至次日 0:00；$`\Delta=1/6`$ 小时。$`S_{d,0}`$ 为首条记录之前的储电量，$`S_{d,144}`$ 为次日 0:00 的储电量。不得把记录标签当成额外的决策起点而漏掉一个十分钟段。

| 符号 | 含义 | 单位/范围 |
|---|---|---|
| $`L_{d,t},P_{d,t}`$ | 小区负载功率、光伏功率 | kW，非负 |
| $`\ell_{d,t}=\Delta L_{d,t},\ v_{d,t}=\Delta P_{d,t}`$ | 十分钟负载电量、光伏电量 | kWh |
| $`N_{d,t}=\ell_{d,t}-v_{d,t}`$ | 净负载电量 | kWh，可为负 |
| $`p_{d,t}`$ | 该交付时段结算电价 | 元/kWh，附件价格为正 |
| $`q_{d,t}`$ | 0:00 确定的计划购电量 | kWh，非负 |
| $`a_{d,t}^{(r)}`$ | 发布时刻 $`r`$ 修订后的**总**购电量 | kWh，非负，不是增量 |
| $`g_{d,t}`$ | 该时段最终锁定的常规购电量 | kWh；问题 1、2 中为 $`q`$ |
| $`e_{d,t}`$ | 紧急购电量 | kWh，非负 |
| $`c_{d,t},b_{d,t}`$ | 母线侧充电量、母线侧放电量 | kWh，非负 |
| $`S_{d,t}`$ | 完成记录 $`t`$ 后的储电量 | kWh |
| $`w_{d,t}`$ | 未利用富余电量 | kWh，非负，无售电收益 |
| $`y_{d,t}`$ | 充电模式指示变量 | 0 或 1；0 表示可放电或空闲 |

$`\mathcal F_r`$ 表示在绝对时刻 $`r`$ 已能获得的历史观测、已发布预报、已锁定合同及当前储电量。$`\mathcal F_{d,t}^{op}`$ 表示当前时段运行层可获得的信息。主模型采用十分钟准静态运行近似：当前段净负载可由实时测量支撑，未来段实际值不可见。用整段实测均值回放时，这一近似必须披露；不是对段内瞬时功率安全的证明。

日前变量必须满足 $`q_{d,t}\in\mathcal F_{d,0}`$。预报时点的调整属于该时点信息集。实时储能动作和补缺电只依赖 $`\mathcal F_{d,t}^{op}`$。这里“属于”表示相对于信息集可测，即相同已知历史必有相同决策。

## 2. 四问共用的物理约束

以下约束对每个时段、每条可实现路径成立。

### 2.1 能量平衡

**式（1）**

```math
g_{d,t}+e_{d,t}+v_{d,t}+b_{d,t}
=\ell_{d,t}+c_{d,t}+w_{d,t}.
```

等价净负载形式为 $`g+e+b=N+c+w`$。$`w\ge0`$ 把“供能不可低于负载”改写为守恒等式；无负荷削减变量。题目未给并网购电功率上限，因此不凭空增加上限。

### 2.2 储能递推与边界

主口径取单向效率 $`\eta_c=\eta_d=0.9`$：

**式（2）**

```math
S_{d,t}=S_{d,t-1}+\eta_c c_{d,t}-\frac{b_{d,t}}{\eta_d},
```

**式（3）**

```math
\begin{aligned}
1200&\le S_{d,t}\le10800,\\
0&\le c_{d,t}\le \frac{5000}{6}y_{d,t},\\
0&\le b_{d,t}\le \frac{5000}{6}(1-y_{d,t}),\\
y_{d,t}&\in\{0,1\}.
\end{aligned}
```

额定容量是 12000 kWh，实际运行边界是其 10%–90%，不能误写成 $`0\le S\le12000`$。主模型把 5000 kW 理解为母线侧限值；若后续澄清为电池侧，应同时变更功率与输出口径。

问题 2–4 中，紧急购电用于满足当前负载，不能主动作为便宜时段的储能充电来源。用以下线性限制表达：

**式（4）**

```math
0\le e_{d,t}\le [N_{d,t}]_+(1-y_{d,t}).
```

其中 $`[N]_+=\max(N,0)`$ 是各情景/当前观测的已给定数值。若 $`e>0`$ 则 $`c=0`$；允许边放电边补充不足电量。在正电价下，无理由同时增加紧急电与富余电；最优补缺量为 $`e=[N+c-g-b]_+`$。若实际实现不使用约束 (4)，必须检查是否出现“为充电而紧急购电”的口径偏离。

### 2.3 初值和跨日

**式（5）**

```math
S_{2025\text{-}01\text{-}01,0}=6000,\qquad
S_{d+1,0}=S_{d,144}.
```

问题1仍加首末6000kWh的日周期条件；第三、四问沿用原建模口径。本次仅调整第二问：题面6000kWh属于1月1日，不属于2月1日；1200kWh是运行下限，不是年末固定值。

第二问现采用队友的1月状态预热：1月1–7日储能空闲，从1月8日至31日以单预测情景三日LP和当天贪心执行推进。2月1日承接1月末SOC，不再直接固定6000。原四分支版的2月初6000来自此前额外采用的“1月空闲”假设；其年末1200是求解结果，不是终值等式。完整来源、预热参数、三日末端门槛与验证边界见下文第4节。

通用物理约束(1)–(5)是实际执行检查标准。第二问日前LP使用下述明确披露的松弛，并非完整实施其中的充放电互斥和应急充电限制。

## 3. 问题 1：确定性日计划模型 M1

附件 1 给出 $`p_t,L_t,\widehat P_t`$。此问按给定光伏预测建立计划模型，不额外制造随机误差。令 $`g_t=q_t,e_t=0,v_t=\Delta\widehat P_t`$。

**式（6）**

```math
\min_{q,c,b,S,w,y}\ C_1=\sum_{t=1}^{144}p_tq_t,
```

满足 (1)–(3)、$`q,w\ge0`$ 及 $`S_0=S_{144}=6000`$。这是一日 144 段的混合整数线性规划。

构造可行解很直接：取 $`c=b=0,S=6000`$，$`q=[\ell-v]_+`$，$`w=[v-\ell]_+`$。该构造证明模型在现有条件下可行，不代表购电费用最优。目标非负，因此存在有限的最优下界。

报告指标为 $`Q_1=\sum_tq_t`$、$`C_1`$，以及六个四小时块内 $`\sum c_t,\sum b_t`$ 和首末储电量。四小时块分别取记录 1–24、25–48、49–72、73–96、97–120、121–144。

## 4. 问题2：三日两阶段随机LP与因果贪心执行 M2

2026-09-11按用户要求改用队友代码的模型。本节完整列出预测、三日LP、执行策略与验证边界。原四分支模型和已完成334天结果保留作历史对照，不再作为本节当前实现。

### 4.1 预测与三日优化

每日0:00用过去数据分别预测负载和光伏，以最近最多3条已完整观测的三日残差形成等概率情景。残差起点不晚于当天之前3天；只用1月滚动误差选择K，1月预热使用默认K。

三日H=432段、q跨情景共享，其余变量按情景独立。日前LP目标为：

**式（7）**

```math
\min\ \sum_{t=1}^{432}p_tq_t
+\sum_s\rho_s\left[\sum_{t=1}^{432}
\left(5p_te_{s,t}+10^{-4}w_{s,t}
+10^{-5}(c_{s,t}+b_{s,t})\right)-\lambda S_{s,432}\right].
```

满足能量平衡、SOC递推、1200–10800kWh边界、各自充放电量不超过5000/6kWh、应急量不超过正净负载、余量不超过负净负载的绝对值，以及三日末端SOC下限。门槛由历史日净负载得到，通常位于4000–8000kWh；λ由固定电价的高价段均值乘放电效率得到。两者是代码参数，不是题设。

连续LP未强制充放电互斥，也没有共同历史节点的非预知动作约束；不能称为原多阶段树的等价求解。具体约束差异及状态认证限制见本节后文。

### 4.2 锁定计划、执行与结算

仅执行并锁定三日q中的当天144段。逐段以当前实测净负载和SOC运行：缺口时优先在功率和SOC下限内放电，再应急补足；盈余时优先在功率和SOC上限内充电，其余作为余量。该执行策略因果且互斥，但不直接执行LP中的情景储能动作。

**式（8）**

```math
C_{2,d}^{actual}=\sum_{t=1}^{144}p_tq_{d,t}
+\sum_{t=1}^{144}5p_te_{d,t}^{actual}.
```

所有计划电量付费，不退款；不将LP末端价值或微小惩罚计入实际费用。

**式（9）**

```math
S_{d,t}=S_{d,t-1}+0.9c_{d,t}-b_{d,t}/0.9,
\qquad S_{d+1,0}=S_{d,144}.
```

2月初SOC来自1月预热，12月末SOC来自最后一天执行，不对两者另设固定数值。队友已提供结果经账本重放核验，当前总费用14356163.53元；这不构成全年最优性或每次LP收敛的证明。

### 4.3 预测与情景构造细节

每段10分钟，Δ=1/6小时；一天144段，三日窗口H=432。附件当天0:10记录对应0:00–0:10，最后记录为次日0:00。净负载电量为N=(L-PV)/6，允许为负。第二问使用附件1固定日内电价p，每三日重复该144维价格，不读取附件3、4。

在第d日0:00，以此前实际数据构造未来三日预测与情景：

- 负载：过去最多31天优先取相同星期的最近min(K,样本数)天，权重正比0.92的样本年龄次方；同星期不足2天则用最近历史天。再加0.3倍同星期逐段差分中位数作为趋势修正。
- 光伏：此前14天加权均值，权重规则同上，预测截为非负；代码未为三个未来日期增加不同天气信息。
- K：用1月内从第8天起的单日滚动误差，从{3,5,7,10,14,21,28}按RMSE、MAE选择。本次审查复算K=7。1月预热使用DEFAULT_K=7，不回灌完整1月校准结果。
- 历史三日残差在起点h构造，预测仅用h之前信息，减去h到h+2的历史实际曲线；当前d仅允许h≤d−3。扫描此前45天可用路径，最终保留最近最多3条，等概率。它们是重叠的历史路径，不是45条独立情景，也不是自动聚类结果。

记当前三日基准预测为F_d，历史残差为R_h，情景为N_s=F_d+R_h，概率ρ_s=1/m。跨年窗口仅预测2026年部分，实际执行与费用仍截止2025年12月31日。

### 4.4 LP约束与末端价值参数

q_t≥0为三日各段共享的计划购电变量；c_{s,t}、b_{s,t}、e_{s,t}、w_{s,t}、S_{s,t}为情景独立的充电、放电、应急购电、余量和储电量。所有电量均为母线侧kWh，S为储能内电量。令U=5000/6，η_c=η_d=0.9。

目标为代码中的费用、微小惩罚和末端价值之和：

```math
\min\ \sum_{t=1}^{432}p_tq_t
+\sum_s\rho_s\left[
\sum_{t=1}^{432}\left(5p_te_{s,t}
+10^{-4}w_{s,t}+10^{-5}(c_{s,t}+b_{s,t})\right)
-\lambda S_{s,432}\right].
```

每个情景和时段满足：

```math
\begin{aligned}
q_t+b_{s,t}+e_{s,t}&=N_{s,t}+c_{s,t}+w_{s,t},\\
S_{s,t}&=S_{s,t-1}+0.9c_{s,t}-b_{s,t}/0.9,\\
1200\le S_{s,t}&\le10800,\\
0\le c_{s,t},b_{s,t}&\le U,\\
0\le e_{s,t}&\le[N_{s,t}]_+,\\
0\le w_{s,t}&\le[-N_{s,t}]_+,\\
S_{s,0}&=S_d,\qquad S_{s,432}\ge F_d^{SOC}.
\end{aligned}
```

动态门槛计算：取此前14天日净负载电量均值μ，及此前最多90天日净负载的10%、90%分位数a、b，令r=clip((μ−a)/(b−a),0,1)，F_d^{SOC}=4000+4000r；代码再夹到[1700,10300]。历史不足或分位数退化时回退6000。该6000是代码的末端门槛回退参数，不是2月初固定电量。

λ为电价不低于其75%分位数的均价乘0.9，再夹到[0.01,5]。门槛、λ、0.3趋势系数及两个微小惩罚均为队友的建模参数，不是题面规定。末端门槛施加在每次预测窗口第三天的情景SOC上，不能当作实际当日末状态的保证。

本模型仅q跨情景共享，不施加共同观测前缀的储能动作相等约束；它是两阶段完全路径补救近似，不能称为旧M2多阶段非预知树的等价实现。三日q共同在当天优化，未来两日实际会再次重算，亦为未来购电决策的开环近似。

优化层为连续LP，没有充放电互斥二进制变量；微小惩罚不构成互斥保证，e上限也不独立保证无应急充电。此处忠实描述队友代码，不将LP松弛写成已满足全部严格运行约束。例如，正净负载时模型允许应急购电与充电同时为正；微小吞吐惩罚也不能替代充放电互斥约束。优化内部是否出现这些动作，仍需保存情景解逐项核对。

### 4.5 执行策略的完整表达

只锁定q的前144段，未来两天计划不成交、不进入当天费用。设当前实际净负载为N_t，缺口g=N_t−q_t，当前储电量为S。

若g>0：

```math
b_t=\min\{g,U,0.9(S-1200)\},\quad
e_t=g-b_t,\quad c_t=w_t=0.
```

若g<0：

```math
c_t=\min\{-g,U,(10800-S)/0.9\},\quad
w_t=-g-c_t,\quad b_t=e_t=0.
```

g=0时四项均为0。更新S←S+0.9c−b/0.9，代码将浮点结果夹至物理边界；验证仍检查原始平衡和状态递推，不能用夹紧掩盖超限。此规则保证实际执行不同时充放电、不应急充电；但不按未来风险主动保留电量，也不是LP情景储能策略的直接执行。执行w没有优化层的负净负载上限。

当天实际费用和状态衔接为：

```math
C_d=\sum_{t=1}^{144}p_tq_t+5\sum_{t=1}^{144}p_te_t,
\qquad S_{d+1,0}=S_{d,144}.
```

不把末端价值奖励或微小惩罚计入实付电费，不退还未使用的计划购电费，不把12月末SOC固定为1200、6000或工作簿已有数值。当前时段实测均值回放沿用十分钟准静态近似，不代表段开始时已知整段均值。

## 5. 问题 3：预报更新下的购电修订模型 M3

### 5.1 发布时刻与锁定区间

预报发布时刻集合为 $`R=\{0,6,12,18\}`$ 小时。在 0:00 根据当时预报形成完整 $`q`$。6:00、12:00、18:00 可以重新形成剩余周期的购电向量 $`a^{(r)}`$；当前时点之前已交付的电量、储能状态和费用锁定。

6:00 发布时记录 1–36 已结束，首个可改记录为 37（标签 6:10）；12:00 和 18:00 同理为 73 和 109。未来草案可以再次修订，但每个交付段最终仅采用其开始前最近允许发布时刻的版本：

**式（10）**

```math
g_t=\begin{cases}
q_t,&t=1,\ldots,36,\\
a_t^{(6)},&t=37,\ldots,72,\\
a_t^{(12)},&t=73,\ldots,108,\\
a_t^{(18)},&t=109,\ldots,144.
\end{cases}
```

这里在开始边界发布的信息可用于紧接着的时段，是发布与执行的时序约定。未采用的新预报仍可更新储能决策，但只有题目允许的时点能改常规购电计划。

### 5.2 主结算公式：原计划不退款

定义相对**最初 0:00 计划**的偏差：

```math
u_t=[g_t-q_t]_+,\qquad h_t=[q_t-g_t]_+.
```

主模型每段的总费用是

**式（11）**

```math
K_t=p_tq_t+1.5p_tu_t+0.5p_th_t+5p_te_t.
```

采用线性表示 $`u_t\ge g_t-q_t,h_t\ge q_t-g_t,u_t,h_t\ge0`$；价格为正且二者仅用于成本时，最优解自然等于上述正部，无需额外二元变量。

**式（12）**

```math
\min_{q,a,\pi}\ C_3=\mathbb E\left[\sum_t K_t\mid\mathcal F_{d,0}\right],
```

满足 (1)–(5)、(10)，以及 $`q\in\mathcal F_{d,0}`$、$`a^{(r)}\in\mathcal F_r`$ 和运行决策的非预知约束。情景树在预报发布节点再揭示新的预报信息，不得把尚未发布的附件 3 行放到根节点。

实际滚动求解时，0:00 锁定 $`q`$；在后续发布时刻，以当前 $`S`$、固定的 $`q`$ 和已交付记录为条件重新优化剩余段。原计划费是沉没项，可以从该次优化目标中删去，但实际累计账本必须保留。

同一未来段在 6:00、12:00 的草案不是两笔新增交易。按 (11) 相对 $`q`$ 对**最终执行量结算一次**，不是将每次草案相对 $`q`$ 的费用全部累加。这是依据题目“计划量与调整量”确定的结算约定；若以后确认每次修订都成交，须另建逐笔合约账本，不能混用。

### 5.3 减少计划购电的支配性

若 $`g_t<q_t`$，保持其他动作不变，改为 $`g'_t=q_t`$，并令 $`w'_t=w_t+(q_t-g_t)`$。供电平衡与储能状态完全不变，紧急电不增加，且减少了 $`0.5p_t(q_t-g_t)`$ 的费用。因此在主口径下存在一个最优解满足 $`g_t\ge q_t`$。

这不表示其他时刻预报没有价值：它们仍能改善储能调度，或用 1.5 倍价格增购替代可能发生的 5 倍紧急购电。是否值得调整应按包含各项费用的真实回放判断。

### 5.4 退款解释：仅作口径对照

若取消部分退回基础电费，但另收 50% 违约费，则

**式（13）**

```math
K_t^{refund}=p_tq_t+1.5p_tu_t-0.5p_th_t+5p_te_t.
```

此时不能照搬仅有下界的 $`h`$ 线性化，因为负系数会使 $`h`$ 人为增大。可直接写为凸分段函数

```math
K_t^{refund}=p_t\max\{0.5q_t+0.5g_t,\ 1.5g_t-0.5q_t\}+5p_te_t,
```

或用正确的分段线性表示。主模型和退款模型须独立命名、独立核算，不能混合得出一个“最优费用”。当前不认定退款解释为官方规定。

### 5.5 判断是否需要其他时刻预报

在相同评价日期、物理参数、初始化和计费解释下，比较允许使用的发布集合 $`\{0\}`$、$`\{0,6\}`$、$`\{0,12\}`$、$`\{0,18\}`$、$`\{0,6,12,18\}`$。比较总费用、应急电量与次数、富余电量，以及末储电量；末状态不同必须同时报告，不能把多耗掉的存量电能直接解释为预测优势。

在相同分布和精确优化下，允许新预报但可选择不调整，会扩大策略集合，最优期望费用不会变大。真实样本外费用可能因预测偏差与有限求解而变差，需以第 5 步的实际验证判定，不能提前声称每次更新都有效。

## 6. 问题 4：波动电价下的 M4-2 与 M4-3

把固定 $`p_t`$ 替换为随机交付价格 $`p_{d,t}`$，并将价格历史加入信息集。附件 4 当天未来实际值只用于结算和评价，不作为事前确定输入。

**式（14）**

```math
\min C_{4-2}=\mathbb E_d\left[\sum_t p_{d,t}q_{d,t}+5p_{d,t}e_{d,t}\right],
```

**式（15）**

```math
\min C_{4-3}=\mathbb E_d\left[\sum_t p_{d,t}q_{d,t}+1.5p_{d,t}u_{d,t}+0.5p_{d,t}h_{d,t}+5p_{d,t}e_{d,t}\right].
```

每个情景同时给出净负载、预报更新和价格，保持可用历史中的相关性。不能无依据地把 $`\mathbb E[pe]`$ 改成 $`\mathbb E[p]\mathbb E[e]`$。有限情景下 $`p_{t,s}`$ 是已给定系数，因此 (14)–(15) 仍为随机混合整数线性结构。

问题 4-2 仅在 0:00 确定常规购电；问题 4-3 允许在指定预报时点修订。主口径用对应交付十分钟段的价格对计划、增减量和应急量分别结算，不用 6:00 这一刻的单个价格替代未来所有段的价格。

若题目后续说明全天价格提前公布，可把价格路径加入 $`\mathcal F_{d,0}`$ 后按已知波动价格求解；在没有说明时，该版本只能标成“已知全天价格基准”，不能当成可实施主策略。
