# 第二问新版模型：季节适应的因果随机调度

版本：M2-v2，2026-09-11。仅新增第二问模型；原 `02_mathematical_models.md`、原数据约定与第三、四问不修改。本文件中的第二问专用预测方案用于取代旧版第二问七日净负载均值方案，不影响其他问。

**交付性质：数学模型及最优策略的定义，不是已算出的全年数值最优解。** 区分以下三种结果：

| 标识 | 含义 | 能否宣称全年最优 |
|---|---|---|
| M2-U：不限制算力 | 给定条件概率模型下，全年非预知策略的最小期望费用 | 仅当该模型精确求解；不等于真实未知分布下最优 |
| M2-U-day：日滚动精确基准 | 同样信息条件下，当天完整随机模型的最优解 | 不能，忽略日末电量后续价值 |
| M2-C：算力受限主方案 | 稀疏情景树、日滚动混合整数优化 | 只能报告当前有限树的最优性或 gap |

“不限制算力”不等于“可以提前读取全年实际值”。完全信息解另记 M2-PI，只能作事后乐观下界。

## 1. 修改依据与可用信息

此前附件审查发现：负载低值重复出现在周五、周六，七日均值会混合不同日型；光伏日均发电量随月份明显变化。上周同日负载与近七日光伏的组合在已有回顾性因果预测比较中，将净负载 MAE 从约 794.97 kW 降至 273.35 kW。这只是预测比较，不能视为调度费用改善或独立留出检验。

仅使用附件1的固定时段电价和初始化曲线，以及附件2中决策时刻已经结束的历史负载、光伏。不引入附件3的预报、附件4的价格或未提供的未来天气。只有一个年度，不能可靠估计跨年重复规律，也不分别训练12个小样本月模型。

令日期为 $`d`$、时段 $`t=1,\ldots,144`$，$`\Delta=1/6`$ 小时。记录标签为区间终点，第一段为00:00—00:10，最后一段为23:50—次日00:00。日前信息 $`H_d`$ 仅含截至当日00:00可用历史；运行层信息 $`H_{d,t}`$ 包含已揭示的当前段净负载。沿用十分钟准静态运行近似：整段实测平均量回放不证明段内瞬时安全。

## 2. 负载与光伏分别预测

下列公式中的功率单位为kW。两个版本采用同一预测接口，避免把算力比较与预测模型差异混淆。

### 2.1 负载：周周期基线与收缩趋势

取 $`K_d=\min(4,\lfloor(d-1)/7\rfloor)`$。历史足够时定义

```math
 B^L_{d,t}=\frac{\sum_{k=1}^{K_d}\rho_L^{k-1}L_{d-7k,t}}
 {\sum_{k=1}^{K_d}\rho_L^{k-1}},\qquad 0<\rho_L\le1.
```

最近周变化用同星期差分估计，避免工作日与低负载日的水平差进入趋势：

```math
 A_{d,t}=\mathrm{median}_{j=\max(8,d-7),\ldots,d-1}
 (L_{j,t}-L_{j-7,t}),\qquad
 \widehat L_{d,t}=\max(0,B^L_{d,t}+\gamma A_{d,t}),\quad0\le\gamma\le1.
```

差分集合为空则 $`A=0`$；无同星期历史时退回已有历史均值，首日使用附件1负载。候选中必须包含“只取上周同日、$`\gamma=0`$”的已检验基线；趋势修正和多周平均不预设必优。

### 2.2 光伏：近期分时曲线适应年内变化

```math
 \widehat P_{d,t}=\max\left(0,
 \frac{\sum_{j\in I_d}\rho_P^{d-1-j}P_{j,t}}
 {\sum_{j\in I_d}\rho_P^{d-1-j}}\right),\qquad
 I_d=\{\max(1,d-W_P),\ldots,d-1\}.
```

近期曲线使发电幅度和清晨/傍晚形状随历史更新；不固定全年日出日落时间，也不把未来真实白昼边界当特征。首日使用附件1光伏预测。该方法是局部季节适应，仍可能滞后于快速日照变化，不声称已建立太阳辐射机理模型。净负载预测电量为

```math
 \widehat N_{d,t}=\Delta(\widehat L_{d,t}-\widehat P_{d,t}).
```

候选窗口 $`W_P\in\{7,14,28\}`$，衰减系数与趋势收缩只能在当前日前已有数据内部滚动验证；历史不足时固定上周负载+近7日光伏基线。不能用全部2—12月挑参数后把同一年度回放称为无偏测试。全过程已经看过全年趋势，最终全年报告应标明回顾性研究。

## 3. 条件残差与随机过程

每个历史日期 $`j`$ 的残差必须由当时可用信息生成的预测构造：

```math
 R^L_{j,t}=L_{j,t}-\widehat L_{j,t|H_j},\quad
 R^P_{j,t}=P_{j,t}-\widehat P_{j,t|H_j},\quad
 R^N_{j,t}=\Delta(R^L_{j,t}-R^P_{j,t}).
```

不能在今天用已含日期 $`j`$ 观测的模型重拟合后生成所谓历史误差。保留同一天负载/PV的配对残差，避免独立抽样破坏相关性；第二问物理与费用只依赖净负载时，可直接建模其配对差 $`R^N`$。

对最近 $`W_R`$ 个成熟残差日赋权

```math
 \omega_{d,j}\propto \exp[-\lambda(d-1-j)]
 \{1+\kappa\mathbf{1}[\mathrm{dow}(j)=\mathrm{dow}(d)]\},
 \qquad\sum_j\omega_{d,j}=1.
```

默认候选 $`W_R=28`$ 或56天；$`\lambda,\kappa\ge0`$。原型的0.97日衰减、同星期乘2只是计时参数，不是经校准的最优参数。报告有效样本量 $`n_{eff}=1/\sum_j\omega_{d,j}^2`$；不能把28天中的四个同星期样本当作充分分布证据。

以分时加权三分位点将净残差划为低、中、高三个状态 $`Z_t`$，代表值为该状态加权均值。状态内尾部被均值压缩，三状态只是离散近似，须检查分位覆盖和尾部风险。

为避免稀疏状态转移出现伪零概率，用收缩估计：

```math
 \widetilde P_{t,ab}=
 \frac{C_{t,ab}+\alpha m_{t+1,b}}{C_{t,a\cdot}+\alpha},\qquad\alpha>0.
```

其中 $`C_{t,ab}`$ 为用权重 $`n_{eff}\omega_{d,j}`$ 累计的转移计数；$`m_{t+1,b}`$ 为加正伪计数并归一的边际概率，因而每项严格为正。$`\alpha`$ 控制向边际分布收缩，无该行样本时自动回退边际。阈值、代表值、概率和参数在该次决策时冻结。当前观测用于条件化；超出阈值范围映射到尾部状态，但物理平衡始终使用真实当前净负载。

M2-U 可采用保留更多残差幅度与历史依赖的完整概率核；若采用上述三状态一阶核，即使全树精确求解，也只能叫“该离散概率模型下最优”，不是连续真实过程精确最优。不得让一个唯一的整日样本轨迹在首段就被识别，从而提前泄露其余轨迹。

## 4. 共同物理与费用模型

下列变量均为每十分钟电量kWh：日前计划 $`q\ge0`$、紧急购电 $`e\ge0`$、充电 $`c\ge0`$、放电 $`b\ge0`$、富余 $`w\ge0`$、储电量 $`S`$。$`N=\Delta(L-P)`$，充电模式 $`y\in\{0,1\}`$。

```math
 \begin{aligned}
 q_{d,t}+e_{d,t}+b_{d,t}&=N_{d,t}+c_{d,t}+w_{d,t},\\
 S_{d,t}&=S_{d,t-1}+0.9c_{d,t}-b_{d,t}/0.9,\\
 1200\le S_{d,t}&\le10800,\\
 0\le c_{d,t}&\le(5000/6)y_{d,t},\\
 0\le b_{d,t}&\le(5000/6)(1-y_{d,t}),\\
 0\le e_{d,t}&\le[N_{d,t}]_+(1-y_{d,t}).
 \end{aligned}
```

紧急购电只补当前负载，不允许同时充电；不凭空增加并网功率限值，不加入售电收益、缺供变量、CVaR目标或电池退化价格。日前计划在当天所有路径上共享，当天不能回写或退款。

```math
 S_{d+1,0}=S_{d,144},\qquad
 C_d^{actual}=\sum_{t=1}^{144}p_tq_{d,t}
 +\sum_{t=1}^{144}5p_te_{d,t}^{actual}.
```

沿用1月储能空闲的启动假设，2月1日 $`S=6000`$；它是固定初始化策略，不是1月最优调度。第二问不加每日回到6000的约束。结算终点12月31日无题设残值，最终只要求储电边界。

## 5. M2-U：不限制算力的最优策略

### 5.1 全年因果随机模型

为说明“全年最优”，设 $`\mathbb P`$ 是由当前历史初始化、可随模拟观测更新的一致全年概率模型。未来日预测参数也必须沿各自历史更新，不能直接把事后拟合的每日分布拼成事前已知路径。令 $`\Pi_{NA}`$ 为满足共同约束且不预知未来的策略集合，则

```math
 J_U^*(H_{d_0},6000)=\inf_{\pi\in\Pi_{NA}}
 \mathbb E_{\mathbb P}\!\left[
 \sum_{d=d_0}^{D}\sum_t(p_tq_{d,t}^{\pi}+5p_te_{d,t}^{\pi})
 \mid H_{d_0},S_{d_0,0}=6000\right].
```

$`d_0`$ 为2月1日，$`D`$ 为12月31日。各日计划只依赖当日零点历史，运行动作只依赖当段已知历史。在适当可积性和最优解存在条件下，达到上式的策略记为 $`\pi_U^*`$；无法证明达到时用下确界而非虚构具体最优向量。

等价日边界Bellman关系为

```math
 V_d(H,S)=\inf_{q_d,\pi_d\in NA}
 \left\{\sum_t p_tq_{d,t}+
 \mathbb E\left[\sum_t5p_te_{d,t}
 +V_{d+1}(H',S_{d,144})\mid H,S\right]\right\},
 \qquad V_{D+1}=0.
```

$`H'`$ 包含新观测及更新预测所需统计量。未来价值 $`V_{d+1}`$ 来自同一全年费用目标，不是任意设置的日末电量奖金。精确求解完整历史树或上述动态规划得到理论最优策略；不在这里声称已经得到其数值。

### 5.2 日滚动精确基准 M2-U-day

将Bellman式中的后续价值设为零，可得旧版日费用目标下的完整随机模型：

```math
 (q_d^*,\pi_d^*)\in\arg\min_{q_d,\pi_d\in NA}
 \left\{\sum_t p_tq_{d,t}
 +\mathbb E_d\sum_t5p_te_{d,t}\right\}.
```

若完整树节点 $`n`$ 的时段为 $`t(n)`$、到达概率为 $`\mu_n`$、父节点为 $`a(n)`$，其确定性等价形式为

```math
 \min\ \sum_t p_tq_t+\sum_n\mu_n5p_{t(n)}e_n,
 \qquad S_n=S_{a(n)}+0.9c_n-b_n/0.9.
```

其余约束逐节点采用第4节，根父状态等于已知初值。每个历史节点只有一套动作，自动满足非预知性。日前费用仅计一次。三状态、144段全展开最多有 $`3^{144}`$ 条叶路径；不限制算力时这是可定义的有限MILP，仍存在状态离散误差。不能用“共同q、每个整日场景独立优化储能”的两阶段模型替代它。

### 5.3 完全信息下界 M2-PI

事后将全年真实净负载全部交给确定性优化器，允许计划与动作预知未来，得到同一物理、启动、终端条件下的事后下界。对同一概率模型有

```math
 \mathbb E[J_{PI}(\xi)]\le J_U^*.
```

它不是可执行方案，不用于填报日前计划。任何全年实际策略在同一路径上的费用不应低于该路径PI最优值；但不同样本、不同分布之间不能混用此不等式。

## 6. M2-C：算力受限的最优解及实施策略

### 6.1 有限树优化

主方案使用第2—3节预测与平滑三状态核。零点先比较两个分支时刻 $`\{00{:}00,12{:}00\}`$ 和三个分支时刻 $`\{00{:}00,08{:}00,16{:}00\}`$。均指区间起点，对应1起算时段 $`\{1,73\}`$ 和 $`\{1,49,97\}`$；代码若用0起算则分别为 $`\{0,72\}`$ 和 $`\{0,48,96\}`$。

在分支处显式展开状态，其余时段按状态概率传播条件均值，保持父子结构。记压缩树为 $`\widehat{\mathcal T}_d`$，则

```math
 (q_d^C,x_d^C)\in\arg\min_{q,x\in\mathcal X(\widehat{\mathcal T}_d)}
 \left\{\sum_t p_tq_t+\sum_{n\in\widehat{\mathcal T}_d}
 \widehat\mu_n5p_{t(n)}e_n\right\}.
```

这是**给定压缩树上的最优解定义**。分支间均值替代可能丢失尾部和相关风险，改变了分布，因此压缩树目标不一定是完整模型目标的上界或下界。

### 6.2 实时执行

日前只执行购电承诺 $`q_d^C`$。每段揭示当前实际净负载后，用真实当前 $`S,N`$ 固定根节点，条件化残差状态；在剩余区间最多放置两个或三个分支，重新求解，仅执行当前节点动作。当天全部 $`q_d^C`$ 固定，下一段再更新。跨日传递真实末SOC。

这是一条可执行的滚动策略，未必等于原日前压缩树策略，也不等于全年最优策略。真实费用由逐段账本计算，不能用日前期望目标代替。

### 6.3 资源预算和最优性标记

建议初始节点预算2000、每次求解10秒、相对gap目标 $`10^{-4}`$。超节点预算时先减至两处分支，再降至单条件均值路径，必须记录实际树；不通过删除物理约束缩减规模。时间上限不等于保证取得解。

若求解器给出可行解目标 $`U`$ 与有效下界 $`L`$，报告 $`L\le J_C^*\le U`$、绝对gap $`U-L`$ 及求解器原始相对gap。分类为：

- 完成搜索并证明最优：有限树最优；浮点数仍须检查可行性。
- 在目标gap内终止：有限树的给定容差最优。
- 达到时限但有校验通过的解：可行次优解，列出gap，不能标成最优。
- 无有效解或物理校验失败：不得执行该解，调用明确的可行回退并记失败。

日前回退取任一非负因果预测计划，例如 $`q=[\widehat N]_+`$；运行回退取 $`c=b=0`$、$`e=[N-q]_+`$、$`w=[q-N]_+`$，保持SOC。这满足平衡、边界和紧急购电上限，但不保证经济性。运行中不能用回退理由修改已经锁定的计划。

求解精度设置与事后物理容差分别记录。计时原型曾被“紧急电与充电同时出现”检查拒绝，严格求解容差重跑通过不构成根因修复证明。正式实现必须保留拒绝逻辑；不能仅看退出状态。建议校验容差 $`10^{-5}`$ kWh、求解器MIP可行性容差 $`10^{-9}`$，小规模验证确认尺度适当后采用。

### 6.4 与理论最优的关系

将最终可执行滚动策略在与M2-U完全相同的全年概率模型上评价，有 $`J_U^*\le J(\pi_C)`$。这并不说明其压缩树上的最优目标大于 $`J_U^*`$，也不保证它在单条实际路径上优于旧模型。优化误差、分布估计误差、树压缩误差、日滚动短视四者必须区分；减小MILP gap只能处理第一项。

## 7. 验证与完成边界

比较旧版7日净负载均值、分开预测的单路径方案、两处分支、三处分支。各方案采用相同实际日期、价格、初始化、跨日连续状态和费用口径。先做多个季节的连续短区间验证，再确定一个方案进行334日回放；独立日期相同SOC的计时试验不能代替连续回放。

预测侧报告逐月负载/PV/净负载MAE、分位覆盖、有效样本量与残差相关性；光伏含大量零值，不用未经处理的MAPE。调度侧报告计划费、应急费、总费、应急电量、末SOC、约束违规、求解时间和gap。若末SOC不同必须展示，不自行修改目标加电量奖金来“公平化”。

本版完成数学重建与公式审查，尚未求得M2-U全年数值最优解，也未完成M2-C新版全年回放。原模型、原求解代码、第三问和第四问保持不变。后续代码与输出应使用独立v2文件/目录，不覆盖旧版本。

## 8. 压缩精度、论文依据、求解器与复现说明

### 8.1 当前压缩方式没有已证明的小误差界

当前方案实质是“稀疏分支+条件均值尾部”，并不是已经实施的、按概率距离优化的情景树缩减算法。五倍应急价格使高净负载尾部很重要；均值相近不能推出调度费用相近。压缩损失可能很大，目前没有本题全年误差估计，不能写成“精度损失可忽略”。

一个可手算的反例：无储能、单时段电价1元/kWh，净负载以各一半概率为0或100kWh。完整随机模型的最优计划是100kWh，期望费用100元；将分布压为均值50kWh后，确定性模型选择计划50kWh，但回到原分布评价，其期望费用为50+5×0.5×50=175元，增加75%。这是解释风险的合成例子，不是本题压缩树损失75%的证据。

论文使用压缩树有合理动机：完整树指数增长、每十分钟重新决策、需要在有限时间内取得可行解；但这些只能论证“为什么需要近似”，不能证明“本近似足够准确”。Heitsch与Römisch的多阶段情景树缩减研究同时考虑概率过程距离与信息结构距离，提示必须保留信息逐步揭示的结构。[作者机构论文记录](https://edoc.hu-berlin.de/items/cb95bca9-ab89-40a7-9929-4cddb7e1e924)

该研究的稳定性结论不能未经条件核对直接套用到本模型的二元运行约束与均值替代算法。若改用距离驱动的树缩减，应另行实现和检验，不能仅修改方法名称。

论文应补以下证据后再评价近似质量：在可精确求解的缩短时域比较完整树与压缩树；在同一组因果评价路径上比较两、三、四处分支策略；关注总费用、应急尾部、SOC和运行时间。缩短时域试验的两边必须使用一致终端条件。保留高净负载事件与连续高残差区间，不能只按曲线均方误差删场景。若增大树后结果稳定，只能称实验稳定性证据，不能当作数学收敛证明。

可用于论文的方法表述（验证完成前不填优势结论）：“为控制多阶段情景树的指数规模，采用保留非预知结构的稀疏分支近似，并通过不同树规模及短时域完整树对照，评价费用、应急风险与运行时间的折中。该方法不保证原始全年随机问题的全局最优。”

### 8.2 MATLAB与Gurobi是否加速

MATLAB是计算环境，Gurobi是优化求解器，二者不能作为同一层次替代品比较。MathWorks官方文档显示当前 `intlinprog` 使用HiGHS；原Python程序也调用HiGHS，因此仅改写成MATLAB不能保证加速。版本、矩阵装配、接口和参数可能影响耗时。[MathWorks官方文档](https://www.mathworks.com/help/optim/ug/intlinprog.html)

Gurobi可以通过Python调用，无需为更换求解器重写为MATLAB。它可能加快某些MILP的搜索或更快缩小gap，但本项目尚未做同模型实测，不能承诺加速倍数。应固定同一情景树、变量约束、硬件、线程预算、可行性容差和目标gap，分别记录建模时间、求解时间、最好可行值与下界。不要用较松gap下的速度来证明求解器更强。

Gurobi官方说明可调 `Threads`、`MIPFocus`，并以 `MIPGap` 控制最好可行解与界的差距；调参效果依实例而变。[Gurobi参数指南](https://docs.gurobi.com/projects/optimizer/en/current/concepts/parameters/guidelines.html)

### 8.3 如何尽量接近并证明最优

对于固定有限树的MILP，分支定界/割平面求解器追求全局界，不是只做局部搜索。首先保证非预知、能量守恒和变量界正确，再采用紧而有效的变量界、合理数值尺度和可行初始解；给予更长时间，让原始/对偶界收敛。增大时间上限不保证在指定时间内证明最优；设置零gap也不自动获得精确算术证明。

报告绝对差距与相对差距，并保留原始日志。即使目标gap为0.01%，也只说明所求有限树目标的优化误差，不说明全年真实费用距真正最优小于0.01%。用于完整模型的下界必须来自同一个完整模型的有效松弛；压缩树最优值不是自动有效的下界。

“全局最优模型”不是已建立模型的质量证书。M2-U定义了在给定概率过程、信息结构和约束下的全局最优策略问题；目前并未完整识别真实概率过程，更未精确计算全年Bellman价值。M2-C还存在日滚动短视与树压缩。因此不能写“本模型已从理论上保证实际全年全局最优”，只能写“建立全局优化问题，并对有限近似模型求解及报告最优性界”。

### 8.4 残差随机性不等于不可复现

已经观测的残差是固定数据；未来误差未知，用概率分布表达不确定性。现有计时原型根据固定历史计算分位点、权重和转移，再枚举分支，没有蒙特卡洛抽样。同一输入和确定的排序/阈值规则产生相同预测与树。

若以后采用残差自助抽样或情景抽样，应固定随机数生成器与种子，同时保存实际抽出的情景和概率；只保存种子不足以跨代码/库版本保证同样样本。需要保存输入哈希、历史截止时刻、参数、残差及状态映射、场景、求解器版本、线程设置和完整日志。

求解过程与数据生成的复现应分开：固定种子不保证墙钟时限截断时返回完全相同的可行解；可能存在多个同费用最优调度。Gurobi官方指出墙钟时限可能导致非确定结果，并提供工作量限制用于更确定的终止控制。受控相同环境可优先使用确定性设置与工作量限制，记录可行解、界和容差，不承诺跨硬件逐位一致。[Gurobi参数指南](https://docs.gurobi.com/projects/optimizer/en/current/concepts/parameters/guidelines.html)
