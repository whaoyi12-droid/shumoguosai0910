本次按用户要求，从队友 `results/问题二_2_加速版.py` 的三日两阶段随机 LP 修改第三问。第二问原文件、已有结果及第四问保留。本文为新实现的模型依据，先确定模型，再进行数值验证；不预先声称全年最优。

## 信息与预测

一天144段，结束标签0:10至次日0:00，电量为功率乘1/6。日初的三日终点固定为第d+3日0:00，日内重新优化剩余432−k段，k=0、36、72、108。负载预测复用队友同星期加权历史与趋势项；未被当前24小时预报覆盖的光伏仍用队友历史均值。仅用当日之前完整实际天拟合负载，日内不临时改变负载预测规则。

在发布时点r，只读取附件3中该时点的24个整点预报。以发布前最后已完成十分钟段的光伏实测作为插值0小时端点，逐段线性插值并截为非负；覆盖当前发布后144段，包括已覆盖的次日部分。更远时段仍用历史光伏预测。禁止读取本日稍后的发布版本。

对历史起点h，用历史当天同一发布时间的附件3重建当时的混合预测，再计算从k到第三日末的实际净负载减预测的残差。只取h≤d−3、过去45天中最近最多3条完整残差，等概率。不能把第二问纯历史光伏预测的残差直接加到第三问官方预报上。无完整残差则用单基准情景；1月状态预热强制单情景。

K仍使用队友1月校准规则（第二问净负载误差），作为继承的参数选择近似，而非声称已经按第三问重新调参。1月预热用默认K=7，不读取月末校准结果。

## 三日 LP 与日内调整

记N为情景净负载电量，x为跨情景共享的常规购电，c、b、e、w、S为情景独立的充、放、应急、余量和储能电量。日初价格系数为p；日内当天剩余段系数为1.5p，后两日为p。约束为：

```math
x_t+b_{s,t}+e_{s,t}=N_{s,t}+c_{s,t}+w_{s,t},\quad
S_{s,t}=S_{s,t-1}+0.9c_{s,t}-b_{s,t}/0.9,
```

```math
1200\le S_{s,t}\le10800,\quad 0\le c_{s,t},b_{s,t}\le5000/6,
\quad 0\le e_{s,t}\le[N_{s,t}]_+,\quad w_{s,t}\ge0.
```

日初x≥0；日内当天剩余段x≥q，其中q是当日0:00锁定的原计划，未来两日x≥0仅为展望变量。S初值取当前实际储电量，三日末端门槛F与价值λ复用队友历史净负载门槛及高价均值规则。

```math
\min\sum_t\alpha_tx_t+
\frac1m\sum_s\left[\sum_t(5p_te_{s,t}+10^{-5}(c_{s,t}+b_{s,t}))-\lambda S_{s,H}\right],
\quad S_{s,H}\ge F_d.
```

相较队友代码，取消w≤[−N]+和弃电微小惩罚：已锁定购电可能超过实际需要，必须允许购入电的余量，不能因此迫使模型同时充放电。保留吞吐微小惩罚，但其不保证互斥。LP仍为两阶段完全路径补救松弛；输出记录内部同时充放电及应急充电的段数。实际控制执行下面的严格因果规则。这是队友框架的可执行近似，不是原多阶段非预知MILP的等价求解，也不证明全局最优。

0:00只锁定当天q。后续发布时点重算未结束部分，每段采用开始前最近一次允许发布的版本，已经执行的时段不可回写。未来两日计划以及当前段之后的草案不提前成交。0:00 LP未显式模拟未来发布时的最优调整，是滚动控制近似；不能声称已联合优化未来信息价值。

## 执行与结算

实际执行沿用队友贪心：缺口g=N−x>0时，b=min(g,5000/6,0.9(S−1200))，e=g−b；盈余时c=min(−g,5000/6,(10800−S)/0.9)，w=−g−c。每步检查平衡、SOC递推、功率限值、互斥和禁止应急充电，跨日状态连续。

主结算口径沿用原第三问：原计划不退款，相对原计划对每段最终执行量结算一次。

```math
C_d=\sum_t[p_tq_t+1.5p_t(x_t-q_t)_++0.5p_t(q_t-x_t)_++5p_te_t].
```

允许免费弃余电时，下调可被保持原计划并增加余量支配，故模型取x≥q，减少费恒为0。若官方确认取消部分退回基础费，则必须修改此约束和目标，本版本不适用退款解释。日内目标省略原计划沉没费及−1.5pq常数，账本仍保留原计划费；末端奖励、吞吐惩罚不计实付费用。
