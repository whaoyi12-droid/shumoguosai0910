**当前完成阶段：第 2 步数学分析、第 3 步确定数学模型。尚未进行全年模型求解、策略效果验证或论文撰写。**

## 关键约定

- 按用户确认，以当天 `0:10` 至次日 `0:00` 的 **144 条记录**为一个周期；每条代表 10 分钟，功率乘以 `1/6` 转为电量。首条之前的状态是当天 `0:00` 的储电量。
- 充放电量统一为交流母线侧 kWh；主模型取充电、放电效率各 90%，对应往返效率 81%。这是对题面效率口径的明确解释。
- 第 3 问主模型按“计划费用 + 调整费用 + 紧急费用”计费；向下调整是否退款存在歧义，两种公式和影响已分别列明。
- 原始附件保持原貌；目前 `附件/附件5/` 内文件均为原始空模板，**不是计算结果**。
- 不向模型输入决策时刻之后的实际负载、实际光伏或实际电价。理想信息基准必须单独标识。

## 本轮可复现检查

Python 3，附件检查需要 `openpyxl`；本轮使用已存在的工作区运行时，未安装全局依赖。

```powershell
python -X utf8 src/audit_inputs.py
python -X utf8 src/check_model_contract.py
git diff --check
```

第一条命令只读原始附件，更新 `docs/input_audit.json`；第二条使用明确标注的合成算例检查周期、效率、能量守恒和计费公式，更新 `docs/model_checks.json`。它们不求解竞赛问题，也不产生 `result*.xlsx`。

后续成果放入 `results/`，源代码放入 `src/`。提交前查看 `git diff`，确保文档、实现和真实运行结果一致。未经讨论不覆盖其他组员成果，不强制推送。
